ROYAUME DES LÉGENDES — DÉMO INTERACTIVE
=======================================

CONTENU
- Accueil avec 8 bannières de factions empilées verticalement.
- Page de faction avec cartes de personnages en grille.
- Fiche de personnage avec emplacement vidéo et narration.
- Bouton « Écouter un exemple » utilisant la voix française disponible dans le navigateur (si prise en charge).
- Maquette responsive pour smartphone et tablette.

OUVRIR SUR WINDOWS
1. Décompresse le ZIP.
2. Double-clique sur index.html pour ouvrir la démo dans Chrome ou Edge.
3. Clique sur une bannière de faction, puis sur un personnage.

IMPORTANT
Les symboles/emojis sont des visuels temporaires. Le site n'est pas encore hébergé en ligne : ce ZIP sert à tester l'interface localement. Pour l'ouvrir sur ton smartphone via une adresse web, il faudra publier les fichiers sur un hébergeur statique gratuit (par exemple GitHub Pages). La maquette importe une police Google Fonts si Internet est disponible ; sinon le navigateur utilise une police de remplacement.

PERSONNALISATION FUTURE
Les factions et personnages se trouvent dans app.js. Chaque faction contient un tableau chars avec nom, rôle, symbole et biographie. On pourra remplacer les symboles par des portraits et ajouter les chemins vers les fichiers MP4 et MP3.


MISE À JOUR DE LA DÉMO
- Les noms des personnages sont désormais affichés en grand sur les portraits des cartes et des fiches.
- Chaque fiche présente deux zones visuelles distinctes : portrait artistique avec nom superposé et zone prévue pour la vidéo MP4 plein pied en boucle.
- La vidéo est encore un emplacement de démonstration : les animations et portraits personnalisés ne sont pas inclus dans cette version. Une animation CSS légère illustre temporairement le mouvement.
- La narration fonctionne actuellement avec la voix du navigateur. Les fichiers audio ElevenLabs pourront être ajoutés plus tard.
- Pour ajouter une vraie vidéo : placer le MP4 dans le dossier media puis remplacer le bloc .idle-stage de app.js par une balise vidéo avec autoplay, muted, loop et playsinline.
